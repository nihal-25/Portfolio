# nihal-m.vercel.app

Personal portfolio site for Nihal M. Next.js (App Router) with a full
static export, Tailwind CSS, no backend.

- All copy lives in [`src/content.ts`](src/content.ts)
- How to edit anything: [CONTENT-EDITING.md](CONTENT-EDITING.md)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # static site in out/
```
